# Conduit 0.8.0

- Show a context meter in the composer for each chat: how full the context window is, and the session cost when the CLI reports one. It updates live during a run and persists with the thread. Claude reports context and cost; Codex reports context only; ACP providers report either or both if the CLI sends `usage_update`.
- Add **Settings → Usage** with Claude Code and Codex plan limits: usage windows with reset times, plan, extra usage, credits and available free resets. Click the meter in a Claude or Codex chat to open it. Reading limits sends no prompt, so it doesn't use any.

Notes: cost is the CLI's own estimate, not a bill. Claude's limits use an API the SDK marks as experimental; if it changes, the Usage tab shows a warning instead of wrong figures. Other CLIs don't report plan limits.

Validation: 80 core tests, TypeScript, production build and Linux AppImage packaging passed. Live Claude (Haiku) and Codex prompts reported context usage, and Claude's cost rose on session resume, confirming it is a running total. Live limit reads returned Claude Pro 5-hour and weekly windows and a Codex Pro Lite weekly window. `scripts/smoke-usage-meter.mjs` checks the meter, warning levels and the Usage tab in Electron using fixture CLIs. Windows and macOS runtime behavior are not locally verified.
