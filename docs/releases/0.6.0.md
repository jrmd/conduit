# Vulp 0.6.0

- Choose the current checkout or create a dedicated Git worktree before starting a conversation. Agent runs, references, changes, commits and PR actions follow the conversation workspace.
- Control agent permissions with Supervised, Auto accept edits, Auto and Full access. Approve or deny requests inline; pending decisions survive renderer reloads and clear on cancellation.
- Use GitHub Copilot alongside Codex, Claude Code, Cursor and OpenCode through the installed Copilot CLI.
- Browse favourite models and configure advertised reasoning, context and speed options with persistent preferences.
- Enjoy a refreshed conversation layout, Files/Activity review tabs, collapsible sidebar, pinned threads, hover previews, compact settled conversations and streamlined PR controls.

Existing conversations and legacy permission settings remain readable. Worktree directories are retained when conversations are deleted. See [chat workspaces](../chat-workspaces.md) and [approval modes](../approval-modes.md) for details.

Copilot authenticated responses and vision remain unverified; local credentials rejected the previously recorded live prompt. Cursor execution is covered by protocol fixtures. Release validation uses deterministic provider fixtures, not fresh authenticated model responses. Linux and Windows packages are published; macOS requires the existing opt-in signing setup.
